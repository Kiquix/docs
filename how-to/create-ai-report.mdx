---
title: "Create a report with AI"
description: "Generate an AI report draft and apply it to a report document."
---

AI report drafts help you turn project evidence, analytics, and AI insights into a structured first draft. Review the draft before applying it to the report.

## Open a report

1. Click **Reports** in the left sidebar.
2. Select the project.
3. Open an existing report document or click **New document**.

## Open the AI report draft

1. In the report editor, open the Fred AI panel.
2. Click **Report Draft**.
3. Click **Generate AI draft**.

Fred starts generating a structured draft from the available project and study AI artifacts.

## Review and apply

1. Wait until the status changes from running to **Draft ready**.
2. Review the generated sections and supporting evidence.
3. Click **Apply draft to report**.
4. Edit the report manually before sharing or exporting.

If you need a new version, use **Regenerate AI draft**. If you need to clear the current state, use **Reset draft state**.

<Note>
  AI report text is a draft. Keep final conclusions tied to evidence you can inspect in Fred.
</Note>
