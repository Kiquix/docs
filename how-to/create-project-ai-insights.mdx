---
title: "Create project insights with AI"
description: "Generate cross-study AI synthesis for a project."
---

Project AI insights combine evidence across studies in a project to help you understand broader patterns, gaps, and decision implications.

## Open project AI insights

1. Click **Projects** in the left sidebar.
2. Select the project.
3. Click **Project AI insights**.

## Generate project insights

1. Click **Generate project insights**.
2. Wait for Fred to finish processing.
3. Review the project summary, findings, evidence coverage, confidence, and recommended next actions.

If project insights already exist, use **Regenerate project insights** only when the underlying evidence has changed or you need a fresh synthesis.

<Warning>
  **Generate project insights** can be unavailable when the project does not have enough completed study artifacts or project-level evidence.
</Warning>
