---
title: "Create a tester pool"
description: "Build a reusable pool of participants from People."
---

Tester pools help you save and reuse participant criteria across studies.

## Create the pool

1. Click **People** in the left sidebar.
2. Click **Create new pool**.
3. Enter the pool name.
4. Optional: add a description.

## Define tester limits

Use the panel near the top of the page to set:

- **Max number of testers** — the maximum number of testers Fred should use from this pool.
- **Min tester's score** — choose **60+**, **70+**, **80+**, **90+**, or **Any**.

## Select criteria

1. Use **Quick search for any criteria to add** to find a criterion directly.
2. Or use the category tabs, such as **Common parameters**, **Employment**, **Tech usage**, or **Purchase habits**.
3. Select criteria such as age, gender, language, country, device, or other available profile fields.
4. Watch **Potential testers** to understand how many testers match the current criteria.

## Save the pool

Click **Save tester pool** when the audience looks right.

<Tip>
  Start with the criteria that matter most for the research question. Adding too many filters can make the pool too narrow.
</Tip>
