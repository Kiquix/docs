---
title: "Create a user interview"
description: "Set up a moderated User Sphere interview study."
---

Use a user interview when you want to run a moderated session with a participant. In Fred, this workflow uses the **User Sphere** method.

## Create the study

1. Open **Projects**.
2. Select the project where the interview study belongs.
3. Click **Add Study from scratch**.
4. Enter the **Study name**.
5. Optional: add a **Study description**.
6. Click **Build Study**.

## Add User Sphere

1. In the study builder, click **Add method** or **Add new block**.
2. Select **User Sphere**.
3. Configure the interview setup and any prototype or session context needed for the call.
4. Use **Setup** and **Scheduler** to prepare session details.
5. Use **Testers** to invite or assign participants.
6. Save your changes.

## Start the interview

When the study is live, open the study and click **Start meeting**. Fred opens the User Sphere session for the presenter.

<Tip>
  Use the **Scheduler** step when you want Fred to manage available interview slots.
</Tip>
